# Story-led script (on demand)

Follow `prompt.md` in this skill's folder, with these differences:
- Script the idea named in the chat. "Script my starred idea" means the newest starred/ doc without a matching "DONE - " doc.
- Ask for the format only if it is genuinely unclear; the default is a Short.
- Also write a **YouTube description** section (two hook lines, a short summary, sources, hashtags) after the edit notes.
- If Google Drive isn't connected in this chat, say so in one line, follow the story rules in prompt.md, and give the whole doc in the reply.
